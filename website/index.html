How it works

One side gives, the other side takes.

Click a display and it becomes the source. The other one is the destination. Every command already knows where things come from and where they go, so there is no "where to?" dialog.

Features

Everything a power user reaches for.

A file manager that does the job of a dozen small tools, and lets you build the rest yourself.

Toolbars

Buttons you build

Drag buttons anywhere, between the displays or along the edges. Each mouse button can run its own commands, and buttons can be menus, split buttons or filter boxes.

Ctrl+E

Index Search

Type part of a name and every match across your home folder and SD card shows at once, sorted, with size and date. Show them all in a tab to copy or tag.

Viewer

See anything

Pictures, music, video, PDFs, text, hex and what is inside archives, in one window. Slideshow, marking, full screen and printing included.

Jobs

Copies you can trust

Every copy runs in its own window with pause, queues per drive, Retry / Skip when a card is pulled, and undo. A notice tells you when a long one is done.

Archives

Zips as folders

Open zip, 7z, RAR and tar as if they were folders, extract with one click, or pack the selection. Password-protected zips too.

sftp://

Servers and shares

Your NAS over SFTP, SMB, FTP or WebDAV, saved by name, with copies that resume where they left off after the network drops.

Columns

Tags, music, photos

Artist and album from music tags, camera and date taken from photos, color labels, star ratings and tags that Dolphin sees too.

Tools

The usual suspects, built in

Synchronize, Find Duplicates, Advanced Rename with undo, checksums, file splitting for FAT32 cards and image conversion.

.js

Make it yours

Your own keys, right-click commands per file type, tab groups, saved filters, status bar layouts and JavaScript scripts that add commands and columns.

Steam Deck

Made on, and for, the Deck.

Directory Duo started as the file manager Desktop Mode was missing. It runs as a Flatpak, is sized for 1280 x 800, and treats the SD card as the first-class drive it is.

  • The SD card and USB drives on the Drives bar by their label, with free space
  • Pinch to zoom a list on the touchscreen or Shift + scroll with the trackpad
  • Add to Steam from the right-click menu Windows programs run through Proton
  • Steam's Browse Local Files opens in Directory Duo when it is the default file manager
  • An ARM64 build for the Steam Frame next to the x86_64 one

Commands

Every button is a little program.

Buttons, keys, menus and the command console all run the same plain commands. Chain them, and one click does the whole job: here, sending every disc image you don't have yet to the SD card.

Saved filters, codes like {sourcepath} and dialogs that ask for a value make a button fit any job you repeat.

Disc images to SDleft-click
Go /home/deck/Emulation/roms/psx
Select PATTERN="@Disc images"
Copy TO=/run/media/deck/SD/roms/psx WHENEXISTS=newer
# right-click: just look
Go /run/media/deck/SD/roms/psx OPENINDEST
